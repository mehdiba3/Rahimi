# کلینیک تخصصی کاشت مو خانم رحیمی — نسخه نمایشی

صفحه معرفی پروژه برای ارائه به کارفرما.

## مشاهده

فایل‌ها را روی GitHub Pages قرار دهید:

1. ریپوی جدید بسازید
2. سه فایل `index.html` ، `style.css` ، `script.js` را آپلود کنید
3. Settings → Pages → Source: main
4. لینک: `https://USERNAME.github.io/REPO-NAME/`

## فایل‌ها

| فایل | نقش |
|------|-----|
| `index.html` | ساختار صفحه |
| `style.css` | استایل |
| `script.js` | انیمیشن و تعامل |

بدون بیلد و بدون وابستگی محلی — فقط Font و Font Awesome از CDN.
